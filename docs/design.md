# 設計原則：四層考據

本站與一般「春秋戰國成語故事」列表的分別，全在這一頁。

一般成語網站把「故事」與「成語」直接等同：講一個故事，末了說「後人因此有了某某成語」。
這種寫法把三件不同的事情壓成一件，結果是讀者無從分辨——哪些是史料明載的、哪些是後人追加的、
哪些根本就是諸子編出來說理的。

本站把它們拆開，每條成語都分四層處理。

---

## 四層是什麼

| 層 | 問的問題 | schema 欄位 |
|---|---|---|
| **本事** | 歷史上實際發生了什麼？何年？何人？ | `benshi` |
| **典源** | 這個說法最早見於哪本書、哪一段？原文作何字樣？ | `dianyuan` |
| **定型** | 「四字成語」這個固定語形，是何時才確立的？ | `crystallisation` |
| **可信** | 本事有多可信？有沒有相牴的記載？ | `reliability` / `variants` |

四者互相獨立。一條成語可以：本事為真而語形晚出；語形早定而本事可疑；
甚至根本沒有本事（諸子寓言），卻依然是理解那個時代的一手材料。

---

## 範例一：臥薪嘗膽——本事為真，語形晚出一千五百年

**本事**（`reliability: 大體可信`）：前 494 年，越王句踐敗於夫椒，入臣於吳；
前 473 年反滅吳國。這段史事《左傳》《國語》皆有詳載，是春秋末年最確鑿的事件之一。

**典源**：《國語·越語》與《左傳》記句踐復國之艱苦，**但通篇沒有「臥薪」，也沒有「嘗膽」**。
「嘗膽」二字首見於《史記·越王句踐世家》：

> 越王句踐反國，乃苦身焦思，置膽於坐，坐臥即仰膽，飲食亦嘗膽也。

司馬遷寫的是「置膽於坐」——把苦膽掛在座位上，坐臥都能看見。**沒有臥薪。**

**定型**：「臥薪嘗膽」四字連用，現存最早見於北宋蘇軾《擬孫權答曹操書》：
「僕受遺以來，臥薪嘗膽」——而蘇軾說的是**孫權**，不是句踐。
把這四個字繫到句踐身上，是南宋人（呂祖謙《左氏傳說》、真德秀等）的事；
到明代梁辰魚《浣紗記》搬演成戲，才徹底固定為今日婦孺皆知的形態。

**所以**：本事在前 5 世紀，「嘗膽」入史在前 1 世紀，四字語形在 11 世紀，
與句踐綁定在 12 世紀，家喻戶曉在 16 世紀。**跨度兩千年。**
一條成語裡疊著五個不同時代的沉積層——這正是值得記錄的東西。

## 範例二：烽火戲諸侯——語形通行，本事可疑

**典源**：《史記·周本紀》記周幽王為博褒姒一笑而舉烽火戲諸侯，
諸侯至而無寇，褒姒乃大笑；其後犬戎真至，舉烽火而諸侯不來，幽王死於驪山之下。

**異說**（`variants`）：2008 年入藏清華大學的戰國楚簡〈繫年〉第二章，
所記完全是另一回事——幽王主動攻伐申國（申侯是他廢后的父親），
申侯聯合繒國與西戎反擊，殺幽王於驪山。**沒有烽火，沒有褒姒一笑，
起因是一場王室繼承鬥爭引發的軍事冒進。**〈繫年〉還記載幽王死後
「邦君諸正」另立幽王之弟余臣為攜惠王，與平王二王並立達二十一年——
這段周室分裂史，《史記》完全沒有。

此外錢穆早已從制度上質疑：烽燧報警是漢代為防匈奴而建的邊防體系，
西周並無此制；即便有，烽火傳訊至諸侯集結需時數日乃至數月，
「諸侯悉至」而後「褒姒大笑」在時間上根本不成立。

**所以** `reliability: 後世附會`。但條目照樣收錄——因為「烽火戲諸侯」
作為一個**敘事**極其重要：它是戰國至漢代「女禍亡國」史觀的標本，
其史料價值不在它記錄了什麼，而在它顯示了漢人如何理解王朝覆亡。

## 可信度五級

| 級別 | 判準 |
|---|---|
| **信史** | 同期或近期文獻（《春秋》《左傳》《國語》）互證，可繫年、可繫人 |
| **大體可信** | 主源可信，但細節有後世增飾（如臥薪嘗膽） |
| **孤證** | 僅一書所載，別無旁證，亦無反證 |
| **後世附會** | 晚出，或與早期文獻、出土材料相牴（如烽火戲諸侯） |
| **寓言** | 諸子所設之譬喻，本無其事（必須配 `type: parable`） |

**「寓言」不等於「沒有價值」。**《韓非子·五蠹》的守株待兔沒有真實的宋人，
但它是理解戰國法家歷史觀的一手材料——韓非用它反對「法先王」，
這個論證本身就是戰國思想史的實據。所以寓言型條目照樣有 `lessons.historical`，
只是分析的對象由「事件」換成「這個譬喻為什麼在那個時代被造出來」。

---

## 啟示為什麼分兩欄

`lessons.historical` 是**史觀分析**：這件事揭示了什麼結構性的東西——
軍禮的約束力、封建宗法的解體、外交作為戰爭的延續。這一欄必填，
且必須扣緊史料，不得作道德訓誡。

`lessons.modern` 是**現代引申**：談判、管理、處世層面的遷移。這一欄選填，
網站生成時會明確標示「引申義，非史料本身所有」——
把兩者混在一起，正是坊間成語書最常見的毛病：
用現代管理學的框架去讀春秋外交，讀出來的只是自己的影子。

## id 命名與交叉引用

四層 id 空間，全部小寫拼音、連字號分隔，由 `scripts/validate.py` 保證引用完整：

| 空間 | 位置 | 例 |
|---|---|---|
| 成語 | `idioms/<id>/` | `tui-bi-san-she` |
| 事件 | `events/<id>.yaml` | `cheng-pu-zhi-zhan` |
| 人物 | `people/<id>.yaml` | `jin-wen-gong` |
| 列國・文獻・分期 | `data/*.yaml` | `jin`、`zuo-zhuan`、`wu-ba` |

成語是**主條目**（資料夾 + `profile.yaml` + 論述 `.md`）；
事件與人物是**節點**（單一 YAML，敘事寫在 `narrative` / `bio` 欄）。
這個不對稱是刻意的：成語是本站的入口與主軸，事件與人物是把成語串起來的骨架，
若三者同等對待，條目數量會爆炸而重心盡失。

## 與哲學家知識庫的分工

先秦思想家（孔子、老子、墨子、孟子、莊子、荀子、韓非……）在
[哲學家知識庫](https://cc-philosophy.vercel.app/) 已有完整條目。
本站 `people/` 中這些人物只寫**史事層面**的小傳（生平、行止、與事件的關係），
思想部分一律以 `philosophy_ref` 欄外連，不重複撰寫。
兩站互為補充：那邊講「韓非想了什麼」，這邊講「韓非死在什麼局裡」。
