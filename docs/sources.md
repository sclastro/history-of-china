# 資料來源與引用規範

文獻的結構化清單在 [`data/sources.yaml`](../data/sources.yaml)（含成書年代、性質、
`ctext` slug、`locus_format` 與各書的 `caveat`）。本頁講的是**規範**：
該查哪一層文獻、怎樣定位、怎樣引用。

## 文獻分四層

| 層 | 文獻 | 在本站的角色 |
|---|---|---|
| **A 編年骨幹** | 《春秋》經、《史記·十二諸侯年表》《六國年表》、《竹書紀年》（古本） | 時間軸的脊椎。兩張年表本身就是「年份 × 列國」的矩陣，直接對應 `timeline.html` 的泳道結構 |
| **B 敘事主源** | **《左傳》**、**《國語》**、**《戰國策》**、**《史記》**世家與列傳 | 史事型成語（`type: historical`）的典源絕大多數出於此四書 |
| **C 諸子** | 《韓非子》《莊子》《列子》《孟子》《呂氏春秋》《晏子春秋》《墨子》《孫子兵法》《荀子》《論語》 | 寓言型成語（`type: parable`）的典源；亦保存大量不見於史書的掌故 |
| **D 出土文獻** | **清華簡〈繫年〉**、馬王堆帛書《戰國縱橫家書》、銀雀山漢簡、睡虎地秦簡、侯馬盟書、郭店楚簡 | `reliability` 與 `variants` 的現代依據——凡與傳世文獻相牴者必須並存互參 |
| **E 後世輯錄** | 《說苑》《新序》《淮南子》 | 保存先秦材料，但已多所潤飾；**孤證不可據** |

### 各層之間怎樣取捨

1. **典源取最早**：`dianyuan[]` 第一條必須是現存最早的出處。若《左傳》與《史記》同記一事，
   典源取《左傳》，《史記》可作第二條或列入 `variants`。
2. **B 層優先於 E 層**：《說苑》《新序》所記若不見於 B 層文獻，`reliability` 至多為「孤證」。
3. **D 層不自動勝出**：出土文獻本身亦是一家之言（清華簡出自楚人之手），
   與傳世文獻相牴時應並存於 `variants`，不得徑以出土者為是而刪去傳世說法。
4. **C 層不得作史實用**：諸子寓言中的歷史人物（莊子筆下的孔子、韓非筆下的宋人）
   一律不可繫年繫事，`type` 必須標 `parable`。

## 引用規範

1. 每條 `dianyuan[]` 必須有 `source`（對應 `data/sources.yaml` 的 id）、
   `locus`（篇章定位）、`quote`（原文）、`translation`（白話）。
   `ctext` 收錄的文獻另須填 `ctext_urn`。
2. `locus` 格式依各書 `locus_format`：
   - 《左傳》：`僖公二十三年`
   - 《國語》：`晉語四`、`越語上`
   - 《戰國策》：`楚策一`、`齊策四`
   - 《史記》：`廉頗藺相如列傳`、`周本紀`
   - 諸子：篇名，如 `五蠹`、`養生主`
3. `ctext_urn` 格式為 `ctp:<書 slug>/<篇章 slug>`，例：
   `ctp:chun-qiu-zuo-zhuan/xi-gong-er-shi-san-nian`。
   網站生成時轉為 `https://ctext.org/<書>/<篇章>/zh`。

   > **注意：ctext 的篇章 slug 並不統一。** 多數典籍用拼音
   > （《左傳》`xi-gong-wu-nian`、《韓非子》`wu-du`、《史記》`shang-jun-lie-zhuan`），
   > 但**《莊子》用英譯**——〈養生主〉是 `nourishing-the-lord-of-life`、
   > 〈秋水〉是 `floods-of-autumn`、〈齊物論〉是 `adjustment-of-controversies`。
   > 另有多層路徑者：《呂氏春秋》作 `shen-da-lan/cha-jin`，
   > 《晏子春秋》作 `nei-pian/za-xia`。新增條目時**務必到 ctext 書目頁核對實際 href**，
   > 不可由篇名逕自拼音。

   `scripts/check_links.py` 會定期覆檢是否失效；但 ctext 會對自動請求回 403，
   該類連結會標為「無法判定」，仍須人手覆核。
4. **直接引語只限已進入公有領域的原典**（先秦兩漢典籍原文）。
   `translation` 一律自譯，不得抄錄他人譯本。
5. **年份**：公元前用負整數（`-632`）；約數用字串 `"c. -632"`；
   不可考填 `null` 並於 `notes` 說明。古曆紀年（`魯僖公二十八年`）填 `year_note`。

## 架構參考（只借架構，不抄內容）

- **楊伯峻《春秋左傳注》**（中華書局，1981）——《左傳》繫年與名物考訂的通行標準
- **劉潔修《漢語成語源流大辭典》**（開明出版社，2009）——語形定型（`crystallisation`）的權威依據
- **錢穆《先秦諸子繫年》**（1935）——戰國人物年代考訂
- **楊寬《戰國史》**（上海人民出版社，1955／增訂本 2003）——戰國段分期與事件繫年
- **李學勤主編《清華大學藏戰國竹簡》**（中西書局，2010– ）——〈繫年〉釋文

> **版權說明**：本站僅借用上述著作的「架構」（分期、繫年、收錄準則）；
> 所有敘述與譯文均為自行撰寫，直接引語只取公有領域原典。
