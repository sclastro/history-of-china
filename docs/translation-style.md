# 今譯與白話敘事標準

本站讀者未必熟悉文言。凡「白話」「今譯」及事件敘事，目標是**現代書面語**——
報章或中文教科書的文字，而不是「淺白一點的文言」。範例見 `events/cheng-pu-zhi-zhan.yaml`。

## 原則

1. **文言詞一律換成今語。** 寡君→我們國君；大夫（稱對方）→你／閣下；詰朝→明天一早；
   辟→避讓；師→軍隊；請成→求和；奔→逃亡／出奔；弒→殺死（臣殺君）。
   「之、其、乎、矣、焉、豈、蓋、遂、乃」等虛詞不應出現在白話中。
2. **補回省略的主語與賓語**，讓每句都知道誰對誰做了甚麼。
3. **長句拆短**，一句只講一件事；因果、轉折用「因為」「於是」「可是」明白標出。
4. **人物稱呼全篇統一**，首次出現可括注別名，例如「子玉（成得臣）」；其後只用一個名字。
   國君用通行謚號，例如「晉文公」而非「晉侯」「公」。
5. **官職、地名、術語首見時略加說明**，例如「下軍副帥」「三十里為一舍」。
6. **不加油添醋。** 只寫史料有載之事；推測須標明「據說」「一說」。
7. 用語參考陳雲《中文解讀》：避免歐化句式（「作出了……的決定」「進行……」），避免冗贅虛詞。
8. 不用廣東口語。標點用全形。

## 事件的結構

- `narrative`：**全部白話**，按時序講述前因、經過、後果；以空行分段，每段一個階段。
  正文不夾文言引語；對話以間接引述寫出。唯一例外是成語本身，可用「」標出。
- `original`：原文選段，三至六段，揀選與成語及關鍵轉折直接相關者。
  每段 `speaker`（說話者，可省）、`locus`、`quote`（原文照錄）、`translation`（按本標準自譯）；
  `source` 缺省時沿用 `sources` 第一條，`ctext_urn` 在 `locus` 相同時亦自動沿用。
- `significance`：一至三句現代書面語。可保留一句關鍵原文，但須緊接「（白話：……）」。

## 覆核清單

以下是首二十個事件經 Poe 改寫後，人手覆核時實際發現的問題，新稿須逐項檢查。

1. **原文逐字照錄。** 先執行 `scripts/verify_original.py`。模型常見的錯誤有：
   改字（居→亦、說→悅、縣→懸）、自擬開頭（「此三子者」）、刪句而不加「……」、
   把兩次提問縮成「復請」。異體字可保留；版本異文須查明底本，不可一律改從維基文庫。
2. **引號內只放原文或成語。** 概念、術語、轉述不加引號（尊王攘夷、分散風險、減灶）；
   原文引語須與典籍字形一致（汎舟之役，不作泛舟）。先執行 `scripts/lint_style.py`。
3. **時序。** 核對事件先後，例如邲之戰先縠渡河在前、欒書議論在後。
4. **史實與數字。** 年份、相隔年數（退避三舍的許諾到城濮之戰是五年，不是十九年）、
   官職（昭陽不是令尹）、所繫成語名稱（結草報恩、驚弓之鳥）須與站內一致。
5. **計劃不可寫成事實。** 說客提出的方略，史書未載其實行者，只能寫作「籌劃」「建議」。
6. **`ctext_urn` 不可自擬。** 只可沿用站內已有者，或依 `data/sources.yaml` 的 slug 規則推出後人手核實。
7. **用字。** 「甚麼」不作「什麼」；國君用謚號（鄭襄公，不作鄭國國君）；同一譯文內稱呼統一（大王／你）。
